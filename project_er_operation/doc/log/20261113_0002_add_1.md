# 生成結果レポート 20261113_0002_add_1(生成の保存先を「保存」ダイアログにする)

指示: 口頭(ファイル操作のUXの問題。RUN > 生成実行が「ファイルを開く」ダイアログで、すでに存在するファイルにしか生成できなかった)

## 実施した内容

- 原因: ポストファイルのパスが空のときに、ポストファイルを選ぶ「開く」ダイアログが出ていた。生成するファイルの保存先を選ぶダイアログではないが、そう見えた。生成するファイルは、保存先を選ぶ手段がなく、出力先の規則どおりに書かれていた。
- 生成するファイルを、ファイルの「保存」ダイアログで選ぶようにした(9.6-1-5)。既定のフォルダとファイル名は、モデルの出力設定(出力フォルダ・出力ファイル名)から決める。まだ存在しないファイルも指定できる。上書きの確認は保存ダイアログに任せ、アプリの確認ダイアログは廃止した。キャンセルしたときは、ファイルを書かずにステータスバーに通知する。
- ポストファイルのパスが空のときは、ポストフォルダの一覧から、モデルの対象DBのものを自動で使う(9.6-1-2)。「開く」ダイアログは、一覧に使えるものがないときだけ出す。
- CLAUDE.md(9.6-1-2、9.6-1-5)と使い方を更新した。

## 仮定

- 保存ダイアログは、出力先が決まっていても毎回表示する(既定の値は入力済み)。
