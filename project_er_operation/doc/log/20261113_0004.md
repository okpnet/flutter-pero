# 生成結果レポート 20261113_0004(UXの問題解決)

指示: `issue/20261113_0004.md`

## 実施した内容

- CLAUDE.md へ統合した(4.1-4、10.2、付録D-39・40)。使い方も更新した。
- **生成ファイルの拡張子を `sql` にする**: 生成ファイルの拡張子が、ポストファイルの `post` と同じ(混同する)という問題。保存ダイアログの既定のファイル名と種類を `sql` にした(`AppSettings.outputExtension`)。設定の「生成ファイルの拡張子」が `post`、または空のときは `sql` にする。ドットや大文字は正規化する(例: `.TXT` は `txt`)。設定画面に注記を追加した。
  - 前回の保存ダイアログ化(`doc/log/20261113_0002_add_1.md`)と合わせて、ポストファイルを選ぶ「開く」ダイアログが、生成するファイルの選択に見える問題は解消している。
- **`.pero` の読込中のオーバーレイとローディング**: ファイルを開くと固まったように見える問題。
  - 読み込みと復元(整合性確認を含む)を、別Isolateで行う(`PeroFile.open`)。結果を別Isolateから受け取れないときは、同じIsolateで読み込む。
  - `EditorSession.busyMessage` に「{ファイル名} を読み込み中…」を設定すると、`MainScreen` が画面全体を覆うオーバーレイ(暗幕)とローディング(くるくる)を表示する。オーバーレイの間は、画面の操作を受け付けない。
  - 表示は、読込と、読込後の最初の画面の描画(テーブルリストなどの再構築)が終わるまで続け、失敗しても必ず消す。読込中に、もう一度開く操作をしても、二重には読み込まない。
