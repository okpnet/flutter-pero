## 3. flutter_js への移行

### 結果

**移行できた。** `flutter_qjs`(パッチ版の複製 `third_party/flutter_qjs`)を削除し、`flutter_js 0.8.7` に置き換えた。生成用JSON、`postgresql.post`、golden テスト(5モデル)、ポストファイルの契約のテストは、変更なしですべて通った。

### 変更点

- `lib/runner/js_post_runner.dart`(新規、旧 `qjs_post_runner.dart` を削除): `QuickJsRuntime2` を使う。
  - **別Isolate**で実行(`Isolate.spawn`)。QuickJS のランタイムはそのIsolate内で生成・破棄する。
  - **タイムアウト**: QuickJS の割込み(`timeout` ミリ秒)に加え、Dart側でも待ち時間に上限を設け、超えたらIsolateを強制終了する。
  - ファイル・ネットワーク・タイマーは使えない: `setTimeout`、`setInterval`、`fetch`、`XMLHttpRequest` などをJS側で無効化した(flutter_js は既定でこれらを提供するため)。テストを追加した。
  - `console.log` はJS側で回収する(旧実装と同じ)。
- 依存: `ffi` が 1.2.1 → 2.2.0、`win32` が 2.6.1 → 5.15.0 に上がった。`file_picker` の固定が解けた(下記)。
- テスト: DLL の準備を `quickjs_c_bridge.dll` に変更(`build/windows/x64/runner/Debug/` からプロジェクト直下へコピー。`.gitignore` 対象)。

### file_picker の扱い

- 固定が解けたため `file_picker` は最新(13.3.3)に上がったが、**13.x の `saveFile` は呼び出し側がバイト列を渡し、`file_picker` 自身が保存する設計**(戻り値は `Uri`)で、本アプリの「保存先のパスを選んでから、一時ファイル経由で原子的に保存する」(4.1-3)と合わない。
- 移行の範囲を広げないため、従来の API を保つ **8.3.7**(`^8.3.7`)に固定した。13.x への移行は、保存フローの見直しが必要な別の課題として残す。

### 注意

- `flutter_js` は同梱の QuickJS のバージョンを公開していない。ES2020 の主要な構文は上記のテストで確認したが、すべての機能の対応は保証できない。
- 以前のビルド出力(`build/windows/x64/runner/Debug/`)に古い `flutter_qjs_plugin.dll` が残っていることがある。`flutter clean` で消える(アプリの動作には影響しない)。

## 4. UX: プロパティペイン

| 変更 | 内容 |
|---|---|
| タブ | 何も選択していない: 「モデル」「ダイアグラム」。テーブル: 「基本」「列」「制約」「トリガー」「クエリ」。ビュー: 「基本」「定義」「クエリ」。リレーションシップ: 「基本」「列対応」「参照規則」。幅が狭いときは折り返す |
| 1項目1行 | 横に並べていた入力欄(論理名/物理名、型と長さ、デフォルトと値、タイミングと行単位など)をすべて縦に1行ずつにした。ラベルは入力欄の上 |
| 間隔 | 入力欄の行間を8pxから16pxに、入力欄の内側の余白を広げた |
| 列 | 1列を見出し(物理名、論理名、型、PK/NotNull/FK)に要約し、見出しをクリックすると項目が開く。ドラッグのハンドルは見出しの左端。「この列を削除」は開いた中にある |
| 制約、トリガー | 名前の決め方などを、プルダウンの入力欄(1項目1行)にした |

- **不具合の修正**: 列の見出しに `PageStorageKey` を使うと、中のテキスト欄のスクロール位置の保存先と衝突して型エラーになるため、`ValueKey` に変えた(テストで検出)。
