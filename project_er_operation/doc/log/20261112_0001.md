### flutter_qjs の扱い

- `flutter_qjs 0.3.7` は **Dart 3.13 ではコンパイルできない**(`lib/src/ffi.dart` の FFI コールバックの戻り値が nullable)。
- `flutter build windows` が通っていたのは、アプリ側から参照していなかったため(未使用の依存はコンパイルされない)。
- `third_party/flutter_qjs` に複製し、`channelDispacher` の戻り値を非nullにする**2行のパッチ**を当てて path 依存にした。QuickJS のネイティブビルド(Windows)と、`postgresql.post` の実行、タイムアウト(無限ループの中断)、ES2020構文、例外の捕捉をテストで確認済み。
- `analysis_options.yaml` で `third_party/**` を解析対象から外している。

## 4. 付録D以外で新たに仮定を置いた事項

1. **リレーションシップの依存関係の既定は「有効」**(付録Aの例が `true` のため)。有効なので、追加時に子の外部キー列をPK・NotNullにする。
2. **トリガー本体の規約**: 本体は「トリガー関数を定義するSQL」。公開(public)のメソッドは `postgresql.post` が同じメソッドを1回だけ出力して `EXECUTE FUNCTION <メソッド名>()` で参照する。入力(inline)の本体は関数名を `{{trigger}}` にする。
3. **外部キーはすべて `ALTER TABLE` で後付け**し、`deferred` かどうかで出力位置を変えない(9.6-3 は「CREATE TABLEの中でも後でもよい」)。
4. `postgresql.post` の追加出力: `COMMENT ON TABLE/COLUMN/VIEW`(コメントが空でないとき)。識別子は、小文字英数字以外と予約語のときだけ `"` で囲む。
5. 一意制約は `ALTER TABLE … ADD CONSTRAINT … UNIQUE`、インデックスは `CREATE INDEX`。
6. 関数ビューは `SELECT * FROM <メソッド名>(引数)`(呼出し式ではなくメソッド名を使う)。
7. 自動配置の「選択がある場合は選択分だけ」は、選択のうち**このダイアグラムに配置されているもの**がある場合に限る。
8. Delete キー: リレーションシップのみを選択しているときは(4.2-4-3に従い)モデルから削除する(確認なし、Undo可)。
9. キャッシュの再生中の用紙ページ再計算は、現在の表示設定(寸法の近似)に依存する。表示設定を変えた直後の異常終了では、ページ数が元と異なる可能性がある。
10. 画像出力の「全体を1枚」のファイル名は `{ダイアグラム名}.png`。
11. 文字幅の近似: 全角=1em、半角=0.55em。
12. ログのレベルは `error / warn / info / debug`、アプリ起動と正常終了を `info` で記録する。
13. 復元したモデルを開くときは、履歴をクリアしたうえで「未保存」の状態にする(`savedPos` を失効)。

## 5. 仕様未定義(0.1-3)

最も単純な方法で暫定実装したもの。

1. 方向入替のとき、新しい親に鍵(PK/ユニーク)が無い場合の扱い → エラーメッセージを出して中止。
2. リレーションシップの列対応を共通列へ付け替えたとき、PK/NotNullの連動は行わない(7-6-7に従う)。
3. 共通列を「子の列」にしたリレーションシップの追加時の自動作成は、実列のみを探す(7-5 は「子テーブルの実列から」)。
4. 貼り付け位置のずらしは、同じクリップボードを繰り返し貼るたびに (20,20) ずつ累積する。
5. 「表示するダイアグラム」で配置を追加するときの位置は、現在のダイアグラム上の位置(無ければ (40,40))。
6. 設定画面で範囲外の値を入力した場合、その欄にエラーを表示してOK/適用を止める。
7. ビューの追加(ダイアログ未実装)は、「今後のバージョンで対応します」というメッセージを表示するだけにした。
8. `.pero` を開いたときの `appVersion` は、ファイルの値をそのまま保持して再保存する(アプリのバージョンで上書きしない)。
