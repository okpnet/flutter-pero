## 3. 付録D以外で新たに仮定を置いた事項

1. 結合条件の提案は、新しいソースより前のソースのうち、**リレーションシップで結ばれている最初のもの**だけを対象にし、そのリレーションシップの全ての列対応を条件にする(複数のリレーションシップがあるときは、IDの小さいもの)。
2. 「条件を追加」で追加する結合条件の初期値は、左=最初のソースの先頭の列、右=このソースの先頭の列。
3. ソースのテーブルを変更したとき、そのソースの結合条件と出力列、そのソースを左に使う他の結合条件を取り除く(列IDが無効になるため)。
4. 出力列名が空のまま OK したときは、元の列の物理名を使う。
5. ビューからソースのテーブルへの点線の依存線(6.6-5)は、今回も未実装。
